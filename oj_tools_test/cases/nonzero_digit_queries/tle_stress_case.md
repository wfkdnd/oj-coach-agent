# 超时压力用例说明

`tle_stress_generator.cpp` 会生成一组容易卡掉暴力做法的完整 OJ 用例：

- `tle_stress.in`：压力输入
- `tle_stress.out`：对应期望输出

- 默认 `m = 30000`
- 默认 `q = 5000`
- `s` 全部为 `9`
- 每个查询都是 `[0, m - 1]`

暴力代码 `tle_bruteforce.cpp` 会对每个查询重新扫描整个字符串，时间复杂度约为 `O(m * q)`。默认压力用例约为 `1.5 * 10^8` 次字符访问，规模比极限数据小很多，但通常已经能卡住逐查询重扫的做法。

前缀和代码 `solution_prefix_sum.cpp` 只需要预处理一次非零数字序列，每个查询通过二分和前缀数组计算答案。

输出文件中的每个查询答案都相同。生成器会先计算 `m` 个 `9` 组成的整数对 `10^9 + 7` 取模后的值，再乘以数字和 `9 * m` 并取模。

如需微调压力大小，可以运行：

```text
tle_stress_generator 20000 4000
```
