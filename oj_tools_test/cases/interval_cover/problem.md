# 判断区间是否覆盖

给定一个目标整数区间 `[L, R]`，以及 `n` 个闭区间 `[li, ri]`。

请判断这些区间合并后，是否能够覆盖目标区间 `[L, R]` 中的每一个整数点。

## 输入格式

第一行包含三个整数：

```text
n L R
```

接下来 `n` 行，每行包含两个整数：

```text
li ri
```

表示一个闭区间 `[li, ri]`。

## 输出格式

如果所有区间可以完整覆盖 `[L, R]`，输出：

```text
YES
```

否则输出：

```text
NO
```

## 样例输入

```text
3 1 10
1 3
4 7
6 10
```

## 样例输出

```text
YES
```

## 样例解释

三个区间合并后可以覆盖从 `1` 到 `10` 的所有整数点，所以输出 `YES`。
